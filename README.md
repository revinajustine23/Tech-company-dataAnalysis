# Tech Company Data Analysis & Relational Database

##  Project Overview
This project presents an end-to-end data analytics workflow for a fictional **Tech Company**. It covers relational database schema design, advanced multi-table SQL queries, Excel data cleaning, and an interactive Power BI dashboard for business insights.

---

## Tools & Technologies
* **Database & SQL:** MySQL / MariaDB (Schema Architecture, Constraints, Multi-table JOINs)
* **Data Preparation:** Microsoft Excel (Cleaning & Data Transformation)
* **Visualization:** Power BI Interactive Dashboard

---

##  Key Features & Deliverables
1. **Relational Schema Design:** Structured tables for employees, departments, and project assignments.
2. **SQL Analytics:** Complex queries evaluating sales performance, employee allocation, and revenue metrics.
3. **Data Cleaning:** Handled missing values, standardized formats, and deduplicated records in Excel.
4. **Power BI Dashboard:** Executive visuals displaying regional sales metrics and performance breakdown.

---

##  Region Focus
Designed & executed from **Arusha, Tanzania**.
